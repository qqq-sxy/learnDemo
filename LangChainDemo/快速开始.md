# 快速开始指南

如果你想要快速搭建项目，可以按照以下步骤操作：

## 🚀 5 分钟快速搭建

### 步骤 1: 克隆或复制项目文件

如果你已经有完整的项目文件，直接复制所有文件到新目录即可。

### 步骤 2: 安装依赖

```bash
pip install -r requirements.txt
```

### 步骤 3: 配置 API Key

创建 `.env` 文件：

```env
DASHSCOPE_API_KEY=你的API密钥
```

### 步骤 4: 运行测试

```bash
# 测试基础功能
python main.py

# 测试文档处理功能
python document_vector_demo.py
```

## 📁 完整文件清单

确保你的项目包含以下文件：

```
LangChainDemo/
├── main.py                    # ✅ 必须
├── document_vector_demo.py    # ✅ 必须
├── requirements.txt           # ✅ 必须
├── .env                       # ✅ 必须（需要自己创建）
├── tools/                     # ✅ 必须
│   ├── __init__.py
│   ├── math_tools.py
│   └── time_tool.py
├── documents/                 # ⚠️ 运行后自动创建
└── chroma_db_langchain/       # ⚠️ 运行后自动创建
```

## ⚠️ 重要提示

1. **API Key 获取**：访问 https://dashscope.aliyun.com/ 获取
2. **Python 版本**：需要 Python 3.8 或更高版本
3. **虚拟环境**：建议使用虚拟环境隔离依赖
