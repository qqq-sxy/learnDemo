Python 基础语法

            Python 是一种高级编程语言，具有简洁明了的语法。

            变量和数据类型：
            - 整数：x = 10
            - 浮点数：y = 3.14
            - 字符串：name = "Python"
            - 列表：numbers = [1, 2, 3]

            控制流：
            - if/else 语句用于条件判断
            - for 循环用于遍历序列
            - while 循环用于重复执行

            函数定义：
            def greet(name):
                return f"Hello, {name}!"

            Python 的特点：
            - 语法简洁，易于学习
            - 丰富的标准库和第三方库
            - 跨平台支持
            - 广泛用于 Web 开发、数据科学、人工智能等领域
