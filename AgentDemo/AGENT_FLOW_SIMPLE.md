## 🔄 ReAct 循环详解

```
┌─────────────────────────────────────────────────────────────┐
│                    ReAct 循环流程                            │
└─────────────────────────────────────────────────────────────┘

Reasoning (推理)
    │
    ├─> LLM 分析用户问题
    ├─> 判断是否需要工具
    └─> 决定调用哪个工具
         │
         ▼
Acting (行动)
    │
    ├─> Agent 执行工具函数
    ├─> 获取工具执行结果
    └─> 将结果添加到消息历史
         │
         ▼
Observing (观察)
    │
    ├─> 将工具结果发送给 LLM
    └─> LLM 观察工具执行结果
         │
         ▼
Reasoning (再推理)
    │
    ├─> LLM 基于结果再次推理
    ├─> 判断是否需要更多工具
    └─> 生成最终回复或继续调用工具
```

## 🎯 数据流转示例

**场景：用户问"现在几点了？"**

```
1. 用户输入
   prompt = "现在几点了？"

2. 添加到 messages
   messages = [
       {"role": "system", "content": "..."},
       {"role": "user", "content": "现在几点了？"}
   ]

3. 第一次 API 调用
   发送: messages + tools定义
   返回: {
       "tool_calls": [{
           "function": {"name": "get_current_datetime"}
       }]
   }

4. 执行工具
   function_name = "get_current_datetime"
   func = tool_map["get_current_datetime"]
   result = func()  # "2025-01-05 14:30:00"

5. 添加工具结果
   messages.append({
       "role": "tool",
       "content": "2025-01-05 14:30:00"
   })

6. 第二次 API 调用
   发送: 完整的 messages（包含工具结果）
   返回: {
       "content": "当前时间是2025年1月5日 14点30分"
   }

7. 返回给用户
   return "当前时间是2025年1月5日 14点30分"
```

## 🔑 核心概念

### 1. tool_map（工具映射表）

```python
# 作用：O(1) 时间复杂度查找函数
tool_map = {
    "get_current_datetime": <function>,
    "add": <function>
}
```

### 2. messages（对话历史）

```python
# 作用：维护完整的对话上下文
messages = [
    {"role": "system", ...},    # 系统提示词
    {"role": "user", ...},      # 用户问题
    {"role": "assistant", ...}, # AI回复
    {"role": "tool", ...}       # 工具结果
]
```

### 3. get_tool_schema()（工具转换）

```python
# 作用：Python函数 → JSON Schema
# 让模型知道有哪些工具可用
```
